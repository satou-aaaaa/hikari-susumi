# 光の進み方あて（hikari-susumi）

身のまわりの光の場面（煙の中の光の筋・鏡・でこぼこの板・水に入れたストロー・光ファイバー など）を見て、光の進み方（直進・反射・乱反射・屈折・全反射）を当てる1日5問の学習ゲーム。正解したら「光はどうなった？」も選ぶ。中学1年理科「光の性質」。

遊ぶ: <https://satou-aaaaa.github.io/hikari-susumi/>
